# Готовые архивы

- [Референсы для 3D-моделирования](BESOGON_3D_MODEL_REFERENCES.zip): 31 отдельный PNG-лист, 6 персонажей в Т-позе, размеры, точки опоры, локальная галерея, схема скелета и требования к `.glb`. Около 51 МиБ.
- [Утверждённое визуальное направление](BESOGON_APPROVED_VISUAL.zip): документ Markdown и три исходных концепт-арта. Около 8 МиБ.

Исходные файлы этих комплектов лежат в `references/models/` и `docs/`. Оригинальные изображения в репозитории — обычные PNG, без Git LFS.

Архивы пересобираются командой `python tools/package_references.py` и копируются сюда из `build/release/`. HTML-прототип находится отдельно в `prototype/besogon.html`.
