# Godot — будущий проект игры

Здесь будет находиться основной проект Godot: `project.godot`, сцены, скрипты и готовые 3D-модели.

**Текущий статус:** перенос ещё не начат. Файла `project.godot` и играбельной Godot-сборки в этом коммите нет. Утверждено визуальное направление; HTML-прототип остаётся отдельным этапом проверки игрового ядра.

Что уже подготовлено:

- [HTML-прототип](../prototype/besogon.html).
- [Требования игрового ядра](../docs/PROTOTYPE_SPEC.md).
- [Утверждённый визуал](../docs/APPROVED_VISUAL.md).
- [31 референс модели и задания](../references/models/00_START_HERE.md).
- [Размеры и требования к `.glb`](../references/models/02_GODOT_EXPORT.md).

При дальнейшей разработке весь Godot-проект будет вестись в этой папке того же репозитория. Модели можно передавать поэтапно, начиная с бойца, серпа и молота. Кэш импорта `.godot/` в Git не входит.
