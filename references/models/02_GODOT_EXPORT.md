# Техническое задание на передачу моделей в Godot

Это рабочие параметры для совместимости ассетов. Художественное направление берётся из утверждённых концептов, а точные размеры — из ведомости этого комплекта.

## Формат и масштаб

- Основной формат — **glTF 2.0 Binary (`.glb`)**. Он подходит для мешей, материалов, скелета и анимаций.
- **1 единица сцены = 1 метр.** Не моделировать персонажей высотой 180 единиц с расчётом на ручное уменьшение при импорте.
- Итоговый ассет в Godot: **+Y вверх; направление лица персонажа — локальное +Z**. В игровом контроллере направление движения будет согласовано с этой ориентацией.
- Оси рабочего файла Blender могут отличаться; проверяй ориентацию готового `.glb` после экспорта. Не менять все кости вручную ради смены осей.
- На итоговом корневом узле модели — масштаб `(1, 1, 1)`, без отрицательного масштаба и случайного поворота.
- Статическим мешам применить масштаб до экспорта. Для персонажа масштаб тела и арматуры привести к нужному размеру **до** привязки и анимации.
- Имена файлов, мешей, костей и клипов — латиницей, без пробелов. ID ассета сохраняется.

## Точки опоры

| Ассет | Origin / pivot |
| --- | --- |
| Персонажи | Между стопами, на уровне опорного пола |
| Серп и молот | В центре хвата рукояти |
| Платок | У основания петли, в месте крепления к шее |
| Пол E01, H01 | Центр верхней ходовой поверхности; толщина уходит вниз от Y=0 |
| Прямые стены, фасад, столб, декор | Центр основания |
| Угловая стена E03 | Наружная нижняя вершина угла; два плеча идут вдоль локальных +X и +Z |
| Арка E05 | Центр прохода на уровне пола |
| Ворота E06 | Общий корень по центру прохода; у каждой створки собственный pivot на внешней оси петель у земли |
| Дверь E10 | Коробка — центр основания; полотно — нижняя точка оси петель |
| Окно E09 | Центр нижней грани вставки |
| Крыша E11 | Центр прямоугольника по плану на уровне карниза |
| Фонарь P04 | Точка крепления кронштейна к стене |

Не запекать большой сдвиг меша относительно его корня. Конкретные значения повторены в CSV и заданиях.

## Модульная улица

- Основная сетка — **2 м**, вспомогательный шаг для расположения декораций — 0,25 м.
- Пол — плитки 2 × 2 м. Их четыре грани должны стыковаться без щелей; рисунок камней должен повторяться без заметной рамки каждой плитки.
- Стены — 4 м длиной, 3 м высотой и 0,30 м толщиной; углы — наружный габарит 2 × 2 м при той же высоте и толщине.
- На торцах и по нижним граням модулей соблюдать точный размер. Сколы и потёртости не должны разрушать стык.
- Для тестовой прямоугольной площадки можно собрать 16 × 12 м из плиток 2 × 2 м; стены и углы подбираются по модульной сетке. Это проверочная компоновка, а не окончательная геометрия всех комнат.
- Проём арки E05 пустой. Ворота, полотно двери и рама отделены друг от друга.
- Фасад E08 содержит одно оконное отверстие под E09. Дверь E10 — отдельный декоративный модуль; отдельный игровой дверной проход для первого прототипа не нужен, переходы идут через арку.
- У крыши ровная плоскость карниза. Труба P08 — отдельный повторяемый предмет.
- Провода столбов, окна с тёплым светом и портальные поверхности добавляются при сборке сцены.

## Геометрия и материалы

- Сохраняй крупные угловатые плоскости. Не превращай концепт в гладкий фотореалистичный скульпт.
- На сгибах персонажей нужна топология, позволяющая поднять руку, согнуть локоть и колено. Нарисованная на листе сетка — иллюстрация, а не готовая топология.
- Все видимые стороны должны иметь корректные нормали. Для пола нужен законченный верх; для стены — перед, зад, торцы и верх.
- Чистая UV-развёртка без случайных перекрытий. Намеренные повторения одинаковых поверхностей допустимы.
- Стандартные PBR-материалы с Base Color и Roughness. Для железа — Metallic по материалу. Normal map — по необходимости.
- Эмиссию глаз и окон удобнее вынести в отдельную маску или материал. Цвета и свечение должны регулироваться в движке.
- Не запекать в текстуру огонь, цветные ореолы, глубокую направленную тень, мокрые отражения, эффект оглушения или освещение сцены.
- Текстуры — PNG; предпочтительно 1024 или 2048 px по задаче. Один компактный атлас на тело персонажа и отдельные материалы оружия удобны для работы.
- Обычная одежда — часть персонажного ассета. Кепку можно оставить отдельным мешем внутри C01 и привязать к голове. Платок W03 не надо одновременно дублировать поверх встроенного платка C01.
- По возможности 1–3 материала на ассет. Это ориентир для первой версии, а не жёсткое ограничение качества.

## Разумный стартовый бюджет

Ориентиры, которые можно уточнить после первого импорта:

| Категория | Ориентир по треугольникам |
| --- | --- |
| Боец | 6–12 тыс. |
| Обычный бес | 3–8 тыс. |
| Босс | 10–20 тыс. |
| Серп или молот | 300–1500 |
| Модуль стены, арка или фасад | 500–4000 |
| Небольшой предмет | 150–2000 |

Важнее силуэт и корректное сгибание, чем точное попадание в число. Мелкий бой камней, волокна дерева и большая часть швов могут быть в текстуре. LOD на первой передаче не обязателен.

## Передача файлов

```text
models/
  C01_tikhon.glb
  C02_demon_walker.glb
  W01_sickle.glb
  ...
source/
  C01_tikhon.blend
  ...
textures/
  C01_tikhon_basecolor.png
  C01_tikhon_roughness.png
  ...
```

В `.glb` по возможности встроить текстуры. Исходные текстуры приложить отдельно, чтобы можно было править материалы. Сложные процедурные узлы Blender перед экспортом запечь в обычные карты.

## Проверка перед передачей

- [ ] Файл повторно открывается или импортируется как `.glb`.
- [ ] Масштаб соответствует ведомости, ноги стоят на Y=0, тело направлено к +Z.
- [ ] Материалы и текстуры не потеряны.
- [ ] Меш не вывернут; торцы и проёмы соответствуют модели.
- [ ] Оружие существует отдельно от кистей.
- [ ] Ворота и дверь могут вращаться вокруг своих осей петель.
- [ ] Стены и пол стыкуются без щелей.
- [ ] При наличии скелета меш связан с ним, а деформации не рвут плечи и локти.
- [ ] В файле нет камер, сценического света, случайных дублей и скрытого тяжёлого скульпта.

Коллизии и `CharacterBody3D`, свет и частицы, логика боя и порталов будут добавлены в проекте. Отдельно моделировать их не требуется.
