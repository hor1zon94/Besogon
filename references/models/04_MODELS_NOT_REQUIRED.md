# Для чего отдельные 3D-модели не нужны

Чтобы не тратить время моделирования, эти элементы будут сделаны при сборке в Godot:

| Элемент | Реализация |
| --- | --- |
| Дуга серпа | Короткий след / простой процедурный меш с материалом |
| Вспышка и кольцо молота | Частицы, кольцо и короткая вспышка света |
| Оглушение | Небольшие значки или частицы над головой |
| Красная зона опасности | Контур / проекция на пол |
| Внутренняя поверхность портала | Материал и частицы внутри модели арки E05 |
| Огонь, дым, искры | Частицы и источники света; модель жаровни P05 уже есть в списке |
| Лужи и мокрый блеск | Материал пола, простые поверхности или декали |
| Мелкие трещины, грязь, следы | Текстуры / декали |
| Бумажные объявления и плакаты | Простой плоский прямоугольник с текстурой, без отдельной ручной модели |
| Провода | Кривая / процедурный тонкий меш между столбами P01 |
| Полосы здоровья, кнопки, счётчики | Интерфейс |
| Коллизии и навигация | Игровые узлы и формы Godot |
| Свет из окон и эмиссия глаз | Материалы и свет в движке |
| Варианты погибших бесов | Поза / простая анимация существующей модели |

Модели предметов награды, сундуков, валюты и мета-прогрессии не запрашиваются: эти системы в текущем игровом каркасе отсутствуют. Дополнительных видов врагов, костюмов и альтернативного оружия в этом комплекте тоже нет.

Для поздних сцен ада подготовлены только два повторяемых модуля H01 и H02. Трон, специальные механизмы и декорации катсцен не нужны до определения постановки этих сцен. Финальные списки имён и лиц могут использовать интерфейс и 2D-портреты; отдельные 3D-модели людей для них сейчас не запрашиваются.
