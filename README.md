# БЕСОГОН

Роглайт-экшен с ручным комбо «серп → молот». Этот репозиторий — основное место хранения файлов проекта: прототипа, дизайна, утверждённого визуала, референсов моделей и будущего проекта Godot.

## Скачать и проверить

- **Весь проект:** [скачать ZIP ветки main](https://github.com/hor1zon94/Besogon/archive/refs/heads/main.zip).
- **Готовые архивы концептов и моделирования:** [GitHub Releases](https://github.com/hor1zon94/Besogon/releases).
- **HTML-прототип:** после распаковки открыть [`prototype/besogon.html`](prototype/besogon.html) в браузере. Сервер и установка зависимостей не нужны.
- **Референсы моделей:** после распаковки открыть [`references/models/GALLERY.html`](references/models/GALLERY.html). Галерея работает локально.

Просмотр HTML-файла на странице GitHub показывает исходный код. Для игры нужно скачать файл или ZIP и открыть HTML локально.

## Что готово

| Часть проекта | Статус |
| --- | --- |
| HTML-прототип на Canvas 2D | Реализованы движение, рывок, ручное комбо, три типа бесов, пять комнат, порталы, пауза и перезапуск |
| Визуальное направление | Утверждено пользователем 9 ноября 2026 года |
| Референсы для моделей | 31 отдельный PNG: 6 персонажей в Т-позе, оружие, модули улицы и декорации; дополнительно 3 исходных концепта |
| Готовые 3D-модели | Пока не переданы; в комплекте находятся изображения и задания на моделирование |
| Проект Godot | Перенос ещё не начат; папка `godot/` пока содержит описание статуса |

Визуальное утверждение не означает утверждения HTML-прототипа. Босс, дьявол и ад в моделировочном комплекте относятся к позднему этапу; их новые дизайны отдельно не утверждены.

## Управление прототипом

- **WASD** — движение.
- **Мышь** — направление удара.
- **ЛКМ** — серп; повторный клик в окне комбо — молот.
- **Пробел** — рывок.
- **Esc** — пауза.

Движение или первый клик начинает забег. Зачистка комнаты открывает портал; после пятой комнаты появляется экран завершения. Звук можно включить кнопкой в интерфейсе.

## Проверки

```sh
node tools/verify_html.cjs
python tools/package_references.py --check
```

Для первой команды нужен Node.js, для второй — Python 3; дополнительные пакеты не требуются. Проверки HTML покрывают симуляцию, ввод, тайминги, урон, переходы, завершение и перезапуск, а вызовы Canvas проверяются через заглушку. **Визуальная проверка в браузере и плейтест пока не выполнены.**

Пересобрать архивы для Releases:

```sh
python tools/package_references.py
```

Архивы появятся в `build/release/`. Исходные изображения доступны в обычном Git; для скачивания и просмотра Git LFS не нужен.
